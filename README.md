CI запускает тесты транзакционной идемпотентности, конкурентной доставки, crash/restart и конфликта payload, выполняет smoke-эксперимент SQLite, компилирует Python и проверяет минимальный набор документов. **Прохождение CI подтверждает только локальные SQLite-инварианты; оно не доказывает exactly-once transport delivery, внешние API effects или production-доступность.** Полные опыты нужно запускать отдельно по протоколу, сохранять seed, логи и платформу.

**Наименование Timeweb в URL — идентификатор портфеля, а не утверждение об одобрении статьи компанией.** Не отправляйте редактору непроверенные результаты в качестве окончательных доказательств.
